# Tiny Habits

A minimal habit tracker for iOS and Android. Built with Capacitor.

## App Store Listing

**Title:** Tiny Habits - Daily Tracker
**Subtitle:** Build better habits, one day at a time
**Keywords:** habit tracker, daily habits, routine tracker, habit builder, streak counter, self improvement, productivity, wellness, mindfulness, goal tracker, daily planner, check-in app

**Description:**
Tiny Habits is the simplest way to build lasting habits. No complex setups, no subscriptions — just a clean, beautiful tracker that helps you stay consistent.

Add your habits, tap to check them off each day, and watch your streaks grow. The circular progress ring gives you instant feedback on how you're doing today. Tap any habit to see your weekly history and current streak.

Features:
- Add unlimited habits with custom colors
- One-tap check-in for each day
- Streak counter to stay motivated
- Weekly history view per habit
- Beautiful, distraction-free design
- Works offline — no account needed
- Your data stays on your device

Perfect for:
- Drinking more water
- Reading before bed
- Morning meditation
- Daily exercise
- Journaling
- Any habit that matters to you

Start small. Stay consistent. Build something great.

## Build Instructions

### iOS
```bash
cd /Users/suhyun/tinyhabits
npx cap open ios
# In Xcode: Product > Archive > Distribute App
```

### Android
```bash
cd /Users/suhyun/tinyhabits
npx cap open android
# In Android Studio: Build > Generate Signed Bundle/APK
```

### Web (for testing)
Open `www/index.html` in any browser.
